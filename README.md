Drink'ina — Responsive Coffee Shop Web Application

Drink'ina is a responsive coffee shop web application built with React.js. The project was developed to create a modern and interactive online ordering experience, with a focus on responsive design, reusable components, state management, and user interactions.

🚀 Features

* Responsive coffee shop interface for desktop, tablet, and mobile
* Browse coffee and drink products
* Product details and "Learn More" interactions
* Shopping cart with quantity management
* Order creation and order management
* User authentication and verification
* Checkout experience
* Delivery and pickup options
* Saved user information and account management
* Dark mode
* Responsive navigation and interactive UI elements
* API integration for authentication and orders

🛠️ Technologies

* React.js
* JavaScript (ES6+)
* Redux Toolkit
* React Router
* HTML5
* CSS3
* Bootstrap
* REST APIs
* Vite
* Git

📂 Project Structure

src/
├── components/     # Reusable UI components
├── pages/          # Application pages
├── motionPages/    # Interactive and animated views
├── redux/          # Redux Toolkit slices and store
├── restApi/        # API requests
├── jsFile/         # Application data and JavaScript utilities
└── assets/         # Images and other assets
```

💻 Getting Started

Prerequisites

* Node.js
* npm

Installation

Clone the repository:

git clone https://github.com/Onifel/WebResponsiveDrinkina.git

Navigate to the project:

cd WebResponsiveDrinkina

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at the local address provided by Vite.
